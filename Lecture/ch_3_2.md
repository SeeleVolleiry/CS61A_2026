## Expressions: 一切皆表达式

**核心思想**： Scheme 程序完全由"*表达式*"构成 ，没有像 Python 那样的"语句"概念。表达式分为两类：

    - 调用表达式（call expressions） ：操作符在前，后跟操作数，类似函数调用；
    - 特殊形式（special forms） ：如`if` 、`and` 、`or` 、`not` ，求值规则与普通调用不同。

**前缀表示法**是整个语言的基础——操作符总是写在操作数之前，整个表达式用括号包裹：
```scheme
(quotient 10 2)          ; => 5
(+ (* 3 5) (- 10 6))     ; => 19
(+ (* 3 (+ (* 2 4) (+ 3 5))) (+ (- 10 7) 6))   ; => 57`
```
**if** 是典型的特殊形式，因为它只求值被选中的分支（普通函数做不到这一点）：

    (if <predicate> <consequent> <alternative>)

**布尔运算**也遵循"短路"规则：
    
    #t (or true) and #f (or false)

    (and e1 ... en): 从左到右，遇 false 即返回 false 并停止
    (or e1 ... en): 从左到右，遇 true 即返回该值并停止
    (not e): e 为 false 返回 true，否则返回 false

## Definitions: 命名与定义——define和lambda

用`define` **给值起名/命名**：
```scheme
`(define pi 3.14)
(* pi 2)          ; => 6.28`
```

用`define` **定义过程**，形式为`(define (<name> <参数>) <body>)` ：
```scheme
(define (square x) (* x x))
(square 21)                ; => 441
(square (square 3))        ; => 81`
```

这里有一个重点：Scheme 支持词法作用域下的局部定义和递归。以经典的牛顿法求平方根为例，内部函数（`good-enough?` 、`improve` 、`sqrt-iter` ）都嵌套在`sqrt` 内部，这也对应你在 Python 里学过的函数内部定义：
```scheme
(define (sqrt x)
  (define (good-enough? guess)
    (< (abs (- (square guess) x)) 0.001))
  (define (improve guess)
    (average guess (/ x guess)))
  (define (sqrt-iter guess)
    (if (good-enough? guess)
        guess
        (sqrt-iter (improve guess))))
  (sqrt-iter 1.0))
```

**匿名函数**`lambda` ，它和`define` 等价但不需要名字：
```scheme
(define plus4 (lambda (x) (+ x 4)))   ; 等价于 (define (plus4 x) (+ x 4))
((lambda (x y z) (+ x y (square z))) 1 2 3)   ; => 12`
```

## Compound values: 复合值（Pair与列表）

**pair**：Scheme 内置的（对）结构，这是构建一切复合数据的基础：
```scheme
(define x (cons 1 2))
(car x)     ; 取第一个元素 => 1
(cdr x)     ; 取第二个元素 => 2`
```

**列表**就是由 pair 递归连接而成，用`nil` （空列表）作为结尾：
```scheme
(cons 1 (cons 2 (cons 3 (cons 4 nil))))   ; 等价于 (list 1 2 3 4)
```
并配合典型的递归过程处理列表——这和你学过的 Python 递归列表处理思想完全一致：
```scheme
(define (length items)
  (if (null? items)
      0
      (+ 1 (length (cdr items)))))`
```

## Symbolic Data: 符号数据（Quotation）

Scheme 不仅能处理数值，还能 把"符号"本身当作数据来对待，这靠的就是引号（quotation） 。

    有值的a 与 b  →  (list a b)  →  (1 2)      ← 求值结果
    带引号'的a与b → (list 'a 'b)  →  (a b)     ← 符号本身

示例代码如下：
```scheme
(define a 1)
(define b 2)

(list a b)
(1 2)

(list 'a 'b)
(a b)

(list 'a b)
(a 2)
```

引用还使我们能够输入复合对象，使用传统的打印表示方式来表示列表：
```scheme
(car '(a b c))
a
(cdr '(a b c))
(b c)
```

## Turtle graphics: 用递归画图

为了方便，一些常用的程序命令有缩写形式，比如 forward 可以简写为 fd。

在 Scheme 中，`begin` 这个特殊结构允许我们在一个表达式中串联多个子命令，这在执行多个操作时非常有用

最后用一个可视化示例收尾，把前面所有概念（抽象、递归、lambda）组合起来。定义了一个通用过程`repeat` ，以及三角形工具：
```scheme
(define (repeat k fn)
  (if (> k 0)
      (begin (fn) (repeat (- k 1) fn))
      nil))

(define (tri fn)
  (repeat 3 (lambda () (fn) (lt 120))))

(define (sier d k)
  (tri (lambda ()
         (if (= k 1)
             (fd d)
             (leg d k)))))

(define (leg d k)
    (sier (/ d 2) (- k 1))
    (penup)
    (fd d)
    (pendown))
```

`tri` 画一个三角形（重复三次、每次左转 120°），而`sier` 是谢尔宾斯基三角形的递归实现——每个大三角形由三条边中点处的三个更小三角形组成。调用`(sier 400 6)` 就能画出分形图。这展示了函数式编程如何用 递归与少量抽象 生成复杂的视觉结构。

## 总结

这一章的核心主张是： 用表达式、定义（`define` /`lambda` ）、复合值和递归来组织程序，而不是依赖显式语句和可变状态。Python 支持"语句式"编程，而 Scheme 让我们看到"一切都是表达式、一切都是值"的纯函数式视角。
