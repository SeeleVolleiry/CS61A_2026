# Q1: Vending Machine

易错点：成功卖出后存库减一，balance归零，有change则要找零。

实现一个售卖单一商品、并能在需要时找零的 VendingMachine 类。所有方法返回描述状态的字符串，要求与 doctest 逐字符完全一致（含标点、空格、$）。

三个方法：

    restock(n) → 加库存并返回 'Current candy stock: 3' 这类消息
    add_funds(n) → 缺货时返回 'Nothing left to vend. Please restock. Here is your $15.'（并退回钱）；否则加余额、返回 'Current balance: $7'
    vend() → 库存和余额都够就出货并找零：'Here is your candy and $2 change.'；否则提示 'Nothing left to vend. Please restock.' / 'Please add $3 more funds.'
    
可用 f-string 简化格式。

    >>> feeling = 'love'
    >>> course = 'CS 61A!'
    >>> combined_string = f'I {feeling} {course}'
    >>> combined_string
    'I love CS 61A!'


# Q2: Cumulative Mul

cumulative: 累积的、渐进的。

写 cumulative_mul(t)，就地修改树 t：让每个节点的 label 变成"它自身 label × 所有子树根节点 label 的积"。

Hint：小心"先改当前节点 label"和"先处理子树"的顺序——该先做哪个？（答案：先递归子树，把子树都改好，再乘上自己，否则会重复把旧 label 乘进去）

示例：Tree(1, [Tree(3, [Tree(5)]), Tree(7)]) → Tree(105, [Tree(15, [Tree(5)]), Tree(7)])

# Q3: Prune Small

prune_small(t, n)（给好了填空骨架）：对每个分支数超过 n 的节点，只保留 label 最小的 n 棵分支，其余删除（prune）。

用 max(iterable, key=...) 找到"该删的最大那棵"；用 list.remove(value) 就地移除第一个匹配项

Hint：max([-7,2,-1], key=abs) 返回 -7；l.remove(2) 会把 [1,2,3,2] 改成 [1,3,2]
